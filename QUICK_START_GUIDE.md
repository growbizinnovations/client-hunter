## 2. Running on Your Server / Cloud

### Option A: Running on any VPS / Cloud Server (Ubuntu/Debian)
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Start the live website & autonomous agent
python server.py
# Or with uvicorn:
uvicorn server:app --host 0.0.0.0 --port 8000
```
Open `http://your-server-ip:8000` in any browser!

### Option B: 1-Click Free Hosting (Render / Railway)
1. Upload this folder / zip to your GitHub repository.
2. Link the repository in [Render.com](https://render.com) as a **Web Service**.
3. It automatically uses the included `Dockerfile` and `Procfile` to launch your live URL!
